# PUBLIC CLINKER DATA TRACK

## Research track separation

The project must keep two research tracks distinct:

### TRACK A — INDUSTRIAL

Objective: raw-material-to-kiln-to-clinker traceability for real industrial plant data.

Data flow:

raw materials -> raw mix -> kiln/process -> measured clinker

This is the main industrial research track.

Required evidence:

- plant record linkage
- raw-material chemistry
- raw-mix proportions
- kiln process records
- clinker sample IDs
- timestamps and production windows
- measured clinker chemistry and quality data
- documented methods and provenance

### TRACK B — LABORATORY / XRD

Objective: measured clinker phase analysis or reference clinker materials.

Data flow:

measured clinker -> XRD/Rietveld -> phase composition

This track is valid for laboratory studies and reference-material characterization, but it must not be presented as equivalent to plant-linked industrial Track A data.

## Important distinction

NIST reference clinker materials are legitimate examples of measured clinker phase-analysis resources. Their value is in phase characterization and reference chemistry. They do not automatically provide:

- raw-material -> raw-mix -> kiln production linkage
- plant-specific process traceability
- industrial production-window continuity

Therefore, they may be used as reference resources, but not as a substitute for traceable plant-linked industrial data.

## Policy

Track B may support method validation, benchmarking, or laboratory comparisons, but it cannot be used to claim that the project has a qualified industrial clinker dataset unless the actual dataset demonstrates raw-material-to-kiln traceability.
