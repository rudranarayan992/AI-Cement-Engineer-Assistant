# MASTER DATA LINEAGE AUDIT
## Executive conclusion
The current repository contains a synthetic clinker demo dataset, a concrete-strength dataset, a plant LCA workbook, and model-output CSVs. None of the current files constitute a qualified industrial clinker target dataset with measured phase/Free CaO values and traceable raw-material-to-kiln-to-clinker lineage.
## Dataset lineage map
- `DiB - Cement Plant data.xlsx` → LCA/inventory workbook; source appears to be a plant-impact study, not measured clinker production samples.
- `Concrete_Data.xls` → concrete mix design dataset with compressive strength; not clinker.
- `blended_cement_concrete_database.csv` → concrete and blended-cement concrete strength dataset; not clinker.
- `AI_Cement_Project/reports/baseline_model_results.csv` → model output table; not source data.
- `AI_Cement_Project/data/raw_materials/raw_materials_database.csv` → raw-material composition database; limited material reference only.
- `AI_Cement_Project/data/raw_mix/raw_meal_samples.csv` → raw meal composition table; synthetic row-level batch data, no process timestamps or sample provenance.
- `AI_Cement_Project/data/cement_master_dataset.csv` → synthetic master dataset generated by `scripts/generate_cement_dataset.py`; includes formula-generated Free CaO and Bogue-like phase values and is not measured ground truth.
- `AI_Cement_Project/data/processed/concrete_*.csv` → processed concrete training/test splits; non-clinker and not a clinker traceability source.
