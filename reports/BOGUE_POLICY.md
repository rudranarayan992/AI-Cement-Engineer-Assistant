# BOGUE POLICY

Bogue-calculated C3S, C2S, C3A, and C4AF are reference or calculated values.

They are not measured XRD/Rietveld phase labels and must not be treated as direct measured ground truth for a clinker ML target.

Bogue calculations may later be used as:

- benchmark values
- comparison figures
- reference features
- diagnostics for phase consistency

They must not be used as:

- measured XRD/Rietveld labels
- synthetic ground truth for industrial clinker prediction
- direct substitute for a measured clinker phase dataset

This rule is retained to prevent scientific overclaiming and target leakage.
